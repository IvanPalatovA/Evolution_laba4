# Лабораторная работа №4 — вариант 6

**Тема:** генетическое программирование диспетчерских эвристик для задачи Job Shop Scheduling Problem (JSSP).

Проект эволюционирует небольшие формулы приоритета операций, а затем применяет их к ранее не виденным производственным задачам. Реализация самостоятельная, на стандартной библиотеке Python 3.10+.

## Запуск

```bash
python3 generate_data.py
python3 run_experiments.py
```

Вторая команда запускает 30 независимых прогонов каждого из двух вариантов GP и прямой ГА на шести тестовых задачах. На обычном ноутбуке выполнение занимает примерно 1–2 минуты. Все результаты детерминированно воспроизводятся благодаря seed из `config.json`.

## Состав

- `project_proposal.md` — краткая заявка на проект;
- `DEMO.md` — готовый сценарий демонстрации на 5–7 минут;
- `jssp.py` — симулятор допустимых расписаний и ручные правила-ориентиры;
- `gp_tree.py` — деревья выражений, защищённые операции и GP-операторы;
- `gp_hyperheuristic.py` — основной эволюционный поиск правил;
- `direct_ga.py` — прямой ГА над операционными последовательностями JSSP;
- `run_experiments.py` — серия экспериментов, статистика и визуализации;
- `report.md` / `ОТЧЕТ.md` — пояснительная записка;
- `outputs/` — уже полученные воспроизводимые результаты.

## Результаты

Два варианта GP получают **строго одинаковый бюджет**: 2 560 симуляций расписаний на один запуск (20 особей × 16 поколений × 8 обучающих задач). По 30 запускам средний нормированный makespan составил 1.3034 для GP с контролем разрастания и 1.3080 для абляции; при этом средний размер дерева уменьшился с 24.6 до 5.3 узла. Подробности, ограничения и план демонстрации приведены в [отчёте](report.md).
